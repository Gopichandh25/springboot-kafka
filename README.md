# springboot-kafka

A hands-on learning repository for building production-grade Spring Boot applications with Apache Kafka.

## What's Inside

- **[LEARNING_GUIDE.md](LEARNING_GUIDE.md)** — A structured, phased learning plan covering everything from Kafka fundamentals to advanced topics like Kafka Streams, Schema Registry, and deployment. Includes coding exercises, exit criteria, and a suggested 10-week study schedule.
- **[Section 1: Kafka Mental Model](section-1-kafka-mental-model.md)** — A practical refresher on Kafka's core concepts (topics, partitions, keys, offsets, consumer groups) with hands-on CLI exercises using a local Docker Kafka setup.
- **[Section 2: Spring Boot Kafka Basics](section-2-spring-boot-kafka-basics.md)** — Comprehensive guide to building your first Spring Boot + Kafka application, with detailed code examples covering project setup, KafkaTemplate, @KafkaListener, externalized configuration, multiple consumer groups, and production-ready patterns.
