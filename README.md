# springboot-kafka

A hands-on learning repository for building production-grade Spring Boot applications with Apache Kafka.

## What's Inside

- **[LEARNING_GUIDE.md](LEARNING_GUIDE.md)** — A structured, phased learning plan covering everything from Kafka fundamentals to advanced topics like Kafka Streams, Schema Registry, and deployment. Includes coding exercises, exit criteria, and a suggested 10-week study schedule.
- **[Section 1: Kafka Mental Model](section-1-kafka-mental-model.md)** — A textbook-style introduction to Kafka's core concepts (topics, partitions, keys, offsets, consumer groups, replication, retention), explaining what each concept is, how it works, and why it matters — with illustrative examples.
- **[Section 2: Spring Boot Kafka Basics](section-2-spring-boot-kafka-basics.md)** — A comprehensive explanation of how Spring Boot integrates with Kafka, covering KafkaTemplate, @KafkaListener, application configuration, serialization, consumer groups, and project structure — with code examples that illustrate each concept in depth.
